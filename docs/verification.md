# 验证范围

## 0.2.2 实机反馈

截至 2026-10-21，部署者已在舞萌、音击等 Sega 机台测试，反馈目前未发现明显问题。反馈没有逐项列出所有游客、双人及版本组合，因此不将其表述为全面兼容认证。中二没有单独的实机测试记录。

## 本地自动验证

Windows x64 和 x86 均已完成 TinyCC 编译、核心状态机测试与独立 DLL 宿主测试。覆盖：

- NFC 帧长、校验、转义、分片、多帧、错误输入恢复和按句柄解码。
- 射频开关穿插待机轮询、初始未知到空闲、刷卡到占用。
- 占用最短保持、短暂轮询不解除、持续待机轮询解除。
- 第二次刷卡，以及 15 分钟、约 18 分钟和两小时的模拟续关。
- 游客启发式、禁用游客线索、网络登录退出线索和空闲信号过期。
- 省略占用超时配置、显式 0、显式正数三种策略。
- 匹配位数宿主的 LoadLibrary、日志生成、HTTP 200 / 503、HEAD、404 和 405。
- 真实 WriteFile IAT 调用、保留已有 Hook 链、后加载测试 DLL 的扫描和采集。

运行测试向普通临时文件写入模拟 NFC 字节，经宿主真实的 WriteFile 导入触发插件；不会向真实读卡器发送数据。长时间续关由核心测试的模拟时钟覆盖，不代表宿主真实等待了两小时。

发布配置为占用最短保持 45 秒、游客线索 6 秒、占用信号超时禁用。宿主测试使用较短参数缩短运行时间。完整测试可通过 `build.ps1` 复现。

发布 DLL 的导入依赖是 Windows 系统组件 `kernel32.dll`、`msvcrt.dll`、`ws2_32.dll`；发布包提供 SHA256 校验文件。

## 限制

- CMake / MSVC 构建路径尚未在当前发布环境执行。
- WinHttpOpenRequest 和 WSASend 路径已编译，但未分别完成独立运行测试。
- 没有在 Windows 7 等其他系统上完成兼容性验证。
- 状态依赖读卡和网络线索；游客、双人、界面切换和硬件故障仍可能出现误判。
- HTTPS 内容、分片网络请求、哈希 API 名及跨进程活动不保证能识别。
- IAT Hook 扫描同进程非 Windows 目录模块，最多 32 个；动态函数地址调用、绕过导入表和后装 Hook 覆盖等情况不保证采集。
- 插件固定到进程退出，配置修改和 DLL 升级需要重启宿主。
- 默认禁用占用超时可支持连续续关，也意味着采集故障时可能保留旧占用。
